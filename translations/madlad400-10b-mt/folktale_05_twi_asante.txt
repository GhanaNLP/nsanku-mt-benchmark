SE ’YOYE A OPETE TE EBINI SO DA

Opete ne Anene na ye wo ho, na Anene se, “Ma yenko twa ’twene bi na yennoro ho.” Ye siim’koo wuram’, na ye ko too oyina. Opete hunu oyina na ose, “Me dee ne yei, na me na me ye opan’ini nti me na metwa kesie.” Anene se, “Mate.” Anene ’so se ofwe, obefwe se tweneboa na esi ho yi, na ono soso ko twaye. Yen nnyina senee atwene.

Opete se obo ne twenem’, eno a ne se:

Futuru! Futuru! manya ntem!

’Pete Kwakye! manya ntem!

Anene so boo ne deem’, eno a ne se:

Anene Kwa! Kwa! Anene Kwa! Kwa!

“There, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, there, “Ye maa so, na ye de koo ye kurom’. Ye ko biee so, Opete se ofwe no dee, ebini pakyia! Anene nso se ofwe no dee, sika se yi a gon! Ankyere bi a na obofuo baye, na obeka kyeree ’Pete se, “Ye se w’Ase awu.” Ose, “Anene ma me pokwa bako memmo mensa na me nko ayie.” Ode pokwa no booye, na okoo ayie no. Ose oko yane so, osene so, ose osore, na pokwa no ate agu yane nom’. Ose, “Ye! Anene adee ayera, na me ko ’fie sen?” Ohuri sii yane nom’ na ope.

"He said, "I'm 'Pete,' and I can't go anywhere, and everywhere I go, I can't get anywhere."

"Nti na mpan’infuo se adufurupe nnye".

We all know that, whether it is one or another, we will never be the same.
